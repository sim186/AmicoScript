# Bundler-managed dependencies replace manual vendoring

`frontend/vendor/` previously held manually pinned, hand-refreshed copies of Tailwind, marked, WaveSurfer, and the Inter font (with a `vendor/README.md` documenting the pin/refresh procedure), specifically to satisfy the offline-only constraint enforced by `tests/test_frontend_assets.py` (no CDN references at runtime — also required for the planned Tauri shell's default CSP). With Vite, these become ordinary npm dependencies (WaveSurfer, marked, `@fontsource/inter`) that the asset build bundles into local, hashed output files in `frontend/` — the offline guarantee is preserved (nothing fetched over the network at runtime) without the manual pinning ceremony. `tests/test_frontend_assets.py` is rewritten to assert this against the *built* `frontend/` output instead of the hand-vendored source directory, which is deleted.
