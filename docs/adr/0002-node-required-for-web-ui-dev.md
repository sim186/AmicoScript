# Node/npm becomes a required dependency for Web UI development

Before this migration, `python run.py` was the entire dev/source workflow — no JS tooling was involved anywhere in the repo (no `setup-node` in CI, no build step in Docker or `package.py`). The Svelte/Vite rewrite requires `npm install` and an asset build (or `npm run dev` with Vite proxying `/api` to the backend) before the Web UI is available from source. We chose not to work around this by committing prebuilt `frontend/` output to git — a committed build artifact causes staleness drift and merge-conflict noise on every UI change. Node is only required when touching the Web UI or building/packaging a release; the backend and TUI remain pure-Python. CI (`tests.yml`, `release.yml`), Docker, and `package.py` all gain a Node build stage/step as a result.
