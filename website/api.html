This page renders openapi.json, which the browser fetches over HTTP. Opening the file straight from disk (file://) is blocked by the browser's same-origin rules — serve the folder instead: 

python -m http.server -d website 8080
# then open http://localhost:8080/api.html

If you are seeing this on the published site, the schema may be missing from the deploy. The reference is generated from the FastAPI app with python scripts/generate_openapi.py; the running app also serves its own copy at http://localhost:8002/docs.
