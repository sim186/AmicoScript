# backend/requirements.txt on purpose: the Docker image and the TUI run headless
# and must not pull a GUI toolkit.
#
# Linux is excluded deliberately. There the backend is WebKitGTK via PyGObject,
# which lives in system packages (gir1.2-webkit2-4.1) that PyInstaller cannot
# relocate into the bundle. Linux builds fall back to a browser tab; a real
# Linux window is Tauri's job (see docs/desktop-shell.md).
